# 배낭 속 미궁 (Backpack Labyrinth)

1인칭 3D 복도를 내려가며 **배낭 격자에 장비를 배치**하고, **같은 아이템 2개를 합성**해 키우는 자동전투 로그라이크 시제품입니다. 전투는 자동으로 진행되고, 승패는 배낭 배치와 합성에서 갈립니다.

- 플레이: https://sigco3111.github.io/backpack-labyrinth/
- 서버 없는 정적 웹 게임이며 진행은 브라우저(localStorage)에 자동 저장됩니다.
- iPhone·안드로이드 터치와 데스크톱 마우스를 지원합니다.

> 이 게임은 Steam의 *Dungeonbound* (louidev)에서 **규칙의 영감**만 받은 오리지널 구현입니다. 원작의 그림, 코드, 이름, 화면 구성은 사용하지 않았습니다.

## 플레이 방법

1. 거점에서 **내려가기**를 누르면 복도를 따라 내려가며 해골을 만납니다.
2. 전투는 자동입니다. 영웅이 공격할 때마다 **배낭 격자를 위→아래, 왼→오른쪽으로 한 칸씩 훑고**, 지나가는 칸에 있는 아이템이 발동합니다.
   - 무기: 피해 / 방패: 보호막 / 물약: 회복
3. 전리품은 **보관함**에 들어옵니다. 아이템을 **끌어서** 배낭 칸에 놓으세요(모양이 있는 조각이라 빈칸에 맞아야 합니다). 아이템을 누른 뒤 **회전** 버튼(또는 PC에서 R키)으로 돌릴 수 있습니다. 선택한 아이템을 한 번 더 눌러도 회전하고, 끄는 도중에도 회전 버튼이 동작합니다.
4. **같은 아이템 위에 같은 레벨 아이템을 올려놓으면 합성**되어 Lv이 1 오릅니다(최대 Lv10).
5. 잠긴 칸은 금화로 해금합니다. 한 번 누르면 비용 표시, 한 번 더 누르면 해금됩니다.
6. 쓰러지거나 **귀환**하면 거점으로 돌아갑니다. **전리품·레벨·영구 강화는 그대로 유지**되고, 금화로 영구 강화 5종(공격/방어/지속/경제/해금)을 구매합니다.
7. 정리가 귀찮으면 **자동 정리**(같은 아이템 자동 합성 + 가치순 자동 배치)에 맡길 수 있습니다. 속도 1x/2x/3x, 전투 로그, 효과음 끄기를 지원합니다. 끝이 없는 무한 진행입니다(5층마다 보스).

## 기술

- Three.js (WebGL) + 순수 JS, esbuild로 번들. 3D 모델은 glb를 한 파일(`game.js`)에 내장합니다.
- 게임 규칙(`core.js`)은 렌더링과 분리되어 있어 Node에서 시뮬레이션으로 밸런스를 검증했습니다.
- 저장: localStorage `bp-labyrinth-v1`.

## 모바일 사용성 개선 (2026-10-29)

- **거점 화면을 전체 화면으로**: 거점(영구 강화) 창이 3D 장면 위 약 310px 오버레이에 갇혀 따로 스크롤되던 것을, 거점 모드에서는 3D 장면을 접고 거점 내용이 배낭 위에 일반 문서처럼 펼쳐지도록 바꿨습니다. 강화 목록 전체가 한 화면 흐름으로 스크롤되고, 내려가기 버튼은 화면 아래에 붙어 따라옵니다.
- **강화 버튼 터치 영역 확대**: 거점의 강화 버튼을 카드 전체 너비로 넓혔습니다.
- **탭 회전**: 선택한 아이템을 한 번 더 누르면 제자리에서 회전합니다(기존: 선택 해제). 끌어서 옮기는 도중에도 회전 버튼으로 회전할 수 있습니다.
- **끌기 가장자리 자동 스크롤**: 아이템을 끌 때 화면 위·아래 가장자리에 가까워지면 패널(또는 보관함)이 자동으로 스크롤되어 멀리 있는 칸에도 놓을 수 있습니다.

## 융합 대장간 (2026-10-29)

서로 **다른** 아이템 2개를 합쳐 새 장비 하나를 만듭니다. 같은 아이템 2개를 겹치는 합성(Lv 상승)과는 별개입니다.

- **사용법**: 사이드의 **융합** 버튼 → 재료 아이템 누르기 → 짝이 될 아이템 누르기 (보라색 테두리가 융합 가능한 짝). 그러면 **미리보기**가 열립니다. 결과 장비, 두 재료와의 능력 비교, 모양(칸 수), 놓일 자리를 보여 주며, **「융합하기」를 누르기 전에는 아무것도 사라지지 않습니다.** 「다른 재료 고르기」로 돌아가거나 **융합 중단**으로 끝낼 수 있습니다.
- **결과**: 서로 다른 기본 아이템 11종의 모든 조합(55가지)에 이름과 능력이 있습니다. 예) 검 + 방패 = 수호의 검, 도끼 + 화염 지팡이 = 불타는 도끼.
- **능력**: 더 강한 쪽(무기 > 방어 > 회복)이 주 능력을 그대로 유지하고, 다른 쪽은 추가 효과(보호막/회복은 원래 값의 75%)나 합산(무기끼리·방어끼리는 합계의 95%)으로 들어갑니다. 한 번의 훑기 발동에서 효과가 함께 나옵니다.
- **모양**: 더 큰 쪽의 모양을 따르고, 작은 쪽이 2칸 이상이면 한 칸을 더합니다 (재료 합계보다 칸을 덜 차지).
- **레벨**: 두 재료의 Lv이 같으면 그대로, 다르면 낮은 쪽에 맞춥니다.
- **제한**: 융합된 장비는 다시 융합할 수 없습니다. 같은 융합 장비 2개(같은 Lv)는 기존처럼 합성으로 Lv을 올릴 수 있습니다. 결과를 놓을 자리가 없으면 융합 버튼이 비활성화되고 재료는 그대로입니다.
- **저장**: 기존 저장은 그대로 이어집니다 (Lv3·합성 6회·열린 칸·보관함을 새 빌드에서 확인).
- 이 규칙은 이 게임의 자체 설계입니다. 원작 *Dungeonbound*의 실제 융합 규칙을 그대로 옮긴 것이 아닙니다.

## 알려진 한계 (시제품)

- 밸런스는 시뮬레이션과 몇 번의 플레이로만 잡았습니다. 실제 손맛 조정이 필요합니다.
- 인접 보너스, 상태이상 다양화, 직업 추가, 상점, 배경음악은 아직 없습니다.
- 3D 해상도·성능은 기기마다 다를 수 있습니다.

## 밸런스·성장 곡선 조정 (2026-10-29)

실제 게임 규칙 코드를 Node에 그대로 올려 자동 플레이 시뮬레이션(정책 4종 × 융합 사용 3종 × 2 시드 × 18회 탐험)으로 측정하고 조정했습니다. 저장 형식은 그대로라 **기존 진행은 그대로 이어집니다.**

### 측정으로 확인한 문제

- **성장이 25층에서 뚝 끊김**: 적 공격력이 층당 1.19배로 커지는데 영웅 체력은 Lv당 +10으로 선형이라, 어떤 정책(공격 우선/균형/경제 우선/해금 우선)으로도 18판 후 전부 25층에서 벽에 막혔습니다.
- **골드가 너무 빨리 남음**: 처치 골드가 층당 1.1배로 불어 5~6판이면 강화 25종·잠금 해금 20칸을 전부 사고, 이후엔 50만g 이상 쌓이기만 했습니다.
- **융합은 압도적이지 않음**: 같은 수준에서 아무 쌍이나 다 융합하면 합성 재료가 말라 오히려 최고 층이 25→20으로 하락. 칸이 부족할 때만 쓰는 정책은 25층으로 동일. 칸당 가치로 보면 1칸+1칸 융합(결과도 1칸)이 가장 효율적이고, 큰 장비끼리는 분할이 근소하게 앞서 **정답이 하나로 고정되지 않는 상태**를 확인해 융합 수치는 유지했습니다.

### 조정 후 측정 (같은 시뮬레이션 조건)

| 지표 | 변경 전 | 변경 후 |
|---|---|---|
| 18판 후 도달 최고 층 | 25층 (모든 정책 동일) | 29~30층 |
| 첫 판 결과 | 5층 보스에서 사망 | 8층까지 생존 |
| 강화·해금 전부 사는 시점 | 5~6판째 | 8~9판째 |
| 18판 후 남는 골드 | 약 41만~54만g | 약 31만~44만g |
| 융합 남용 정책 최고 층 | 20~24층 (합성 집중 대비 열세) | 25층 (여전히 열세, 격차 유지) |

25층 부근에서 멈추던 진행이 30층 부근까지 매 판 조금씩(28→29→30) 뚫고 나가는 곡선으로 바뀌었고, 사망·귀환을 반복하는 장르 특성은 그대로입니다.
